# Contributing to dynamic-translate 🌐

*(Disponível em Português abaixo / Available in Portuguese below)*

Thank you for your interest in contributing to **dynamic-translate**! We welcome contributions from developers worldwide to make i18n workflows simpler, faster, and more accessible.

---

## 🇬🇧 English

### Code of Conduct
Please be respectful, constructive, and collaborative in all issues, discussions, and pull requests.

### Development Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-org/dynamic-translate.git
   cd dynamic-translate
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Run tests**:
   ```bash
   npm test
   ```
4. **Build the package**:
   ```bash
   npm run build
   ```

### Pull Request Process
1. Fork the repo and create your branch from `main`:
   ```bash
   git checkout -b feature/my-new-feature
   ```
2. Write unit tests in `tests/` for any new feature or bugfix.
3. Ensure all tests pass (`npm test`) and typechecking succeeds (`npm run typecheck`).
4. Commit your changes with clear and descriptive messages.
5. Push to your fork and submit a Pull Request.

## 🇧🇷 Português

### Como Contribuir
Agradecemos muito o seu interesse em contribuir para o **dynamic-translate**!

### Configuração do Ambiente
1. **Clonar o repositório**:

2. **Instalar dependências**:
   ```bash

   ```
3. **Executar testes unitários**:
   ```bash
   npm test
   ```
4. **Compilar o pacote**:
   ```bash
   npm run build
   ```

### Processo de Pull Request
1. Crie uma branch para sua funcionalidade ou correção:
   ```bash
   git checkout -b feature/minha-feature
   ```
2. Adicione ou atualize testes unitários na pasta `tests/`.
3. Certifique-se de que todos os testes passaram (`npm test`) e que não há erros de tipagem (`npm run typecheck`).
4. Abra um Pull Request detalhando o problema resolvido ou a melhoria implementada.
